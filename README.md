# bentruong.dev

Personal résumé site for Huy Truong — React 19 + Vite + MUI v7, green & gold theme with light/dark mode.

- **Edit content:** everything lives in `src/data.js` (wrap text in `**…**` to highlight it).
- **Theme:** `src/theme.js` (palettes + fonts: Fraunces / Inter / JetBrains Mono).
- **Résumé PDF:** replace `public/Huy_Truong_Resume.pdf`.

```bash
npm install
npm run dev      # local dev
npm run build    # outputs dist/
```

Custom domain: `public/CNAME` → `bentruong.dev` (used by GitHub Pages; harmless elsewhere).
